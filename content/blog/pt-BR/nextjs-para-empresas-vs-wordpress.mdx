A pergunta volta toda semana: **"vale migrar do WordPress pra Next.js?"** A resposta curta é "depende do que você precisa". A resposta útil é entender os trade-offs reais e decidir com dado, não com hype.

Esse post compara nas frentes que importam: performance, SEO, custo, segurança e contratação de dev. Sem religião.

## A comparação direta

| Dimensão | WordPress | Next.js |
|----------|-----------|---------|
| Tempo de carregamento (LCP típico) | 2.5 – 5s | 0.6 – 1.5s |
| Lighthouse score (médio, mobile) | 35-70 | 90-100 |
| Custo de infra | $5-30/mês (shared) ou $50+ (VPS) | $0-20/mês (Vercel free tier cobre muito) |
| Atualização de segurança | Manual ou plugin | Build incremental do framework |
| Tempo pra criar nova página | 5 min (CMS) | 30 min (código) ou 5 min (CMS headless) |
| Curva de aprendizado pra editores | Baixa | Depende do setup |
| Vulnerabilidades de plugin | Vetor #1 de hack | Quase inexistente |

## Quando Next.js vence

Migre pra Next.js quando:

- **Performance importa pro negócio.** Se você vende online ou compete por SEO, cada 100ms de LCP = 1-2% de conversão. WordPress raramente entrega menos de 2s sem investimento pesado em otimização.
- **Você precisa de funcionalidade dinâmica.** Calculadoras, formulários multi-step, integrações com APIs, dashboard logado — WordPress vira gambiarra. Next.js é nativo nisso.
- **Seu time tem (ou pode contratar) developer.** Mercado de dev React/Next.js é gigante. Mercado de bom dev WordPress encolheu.
- **Você quer Core Web Vitals impecáveis.** Google penaliza site lento desde 2021. Next.js + Vercel entrega 95-100 no Lighthouse sem esforço.
- **Segurança é crítica.** Site institucional de empresa B2B, governo, financeiro. Plugins WordPress são vetor recorrente de invasão.

## Quando WordPress ainda é certo

Somos suspeitos (construímos em [Next.js](/pt-BR)), mas WordPress ainda é a escolha certa quando:

- **Conteúdo muda diariamente e editores não-técnicos publicam.** Blog de notícia, revista, magazine. WordPress nasceu pra isso e é imbatível.
- **Budget é R$ 5-15k total.** WordPress + tema bom + dev freelancer entrega site institucional decente. Next.js vai custar 3-5x mais nessa faixa.
- **Você precisa de loja virtual barata e simples.** WooCommerce + tema cobra menos pra começar que Next.js + Stripe + tudo customizado.
- **Você quer parar de pagar dev após o lançamento.** WordPress + cliente editando direto = manutenção quase zero. Next.js precisa de dev pra mudanças estruturais.

## O custo real da migração

Não é só o preço da nova build. Some:

- **Migração de conteúdo.** WordPress → Next.js precisa de export, parse, reformat. Para 200 páginas: 20-40 horas.
- **301 redirects.** Cada URL antigo precisa apontar pro novo. Esquecer isso = perder 30-60% de tráfego orgânico nos primeiros 90 dias.
- **Headless CMS (se editores precisam).** Sanity, Contentful, Payload — $0-200/mês.
- **Treinamento de equipe.** 2-4 horas pra editores aprenderem o novo fluxo.

Soma realista pra um site institucional de 50 páginas: **R$ 25-60k de build + 1-3 semanas de migração**.

## SEO depois da migração

Esse é o medo número um. A verdade:

- **Curto prazo (1-3 meses):** queda de 10-30% no tráfego orgânico se você fizer redirects bem feitos. Se esquecer redirects: queda de 50-80%.
- **Médio prazo (3-6 meses):** recuperação total + ganho de 10-40% por causa do Core Web Vitals melhor.
- **Longo prazo (6+ meses):** ganho consistente se você manter publicando bom conteúdo.

Truque pra reduzir risco: faça a migração técnica e mantenha URLs idênticas por 60 dias antes de qualquer rebranding ou IA de conteúdo.

## A decisão de stack pra cada caso

**Site institucional + landing pages:** Next.js + Sanity ou Payload. Sem dúvida.

**Blog/magazine de notícias:** WordPress, a não ser que você tenha time de dev dedicado.

**E-commerce até R$ 1M ARR:** Shopify ou WooCommerce. Acima disso, vale Next.js + Shopify Hydrogen ou Medusa.

**App logado com dashboard:** Next.js. WordPress nunca foi feito pra isso.

**Portal governamental:** Next.js + headless CMS. Mais auditável, mais seguro, melhor performance.

## Checklist de quando vale o investimento

Marque mentalmente:

- [ ] Site atual tem Lighthouse < 70 no mobile
- [ ] Tráfego mensal > 10k visitas (cada % de melhoria conta)
- [ ] Já fui hackeado ou vivi com medo disso
- [ ] Plugins quebram quando atualizo
- [ ] Quero adicionar funcionalidade custom e cada plugin é um pesadelo
- [ ] Custo de manutenção mensal passa de R$ 1k

3 ou mais? Vale conversar sobre migração. Menos que isso? Mantenha o que está e invista o dinheiro em outra coisa.
