A pergunta volta todas as semanas: **"vale a pena migrar do WordPress para Next.js?"** A resposta curta é "depende do que precisa". A resposta útil é perceber os trade-offs reais e decidir com dados, não com hype.

Este artigo compara nas frentes que importam: performance, SEO, custo, segurança e contratação de developers. Sem religião.

## A comparação direta

| Dimensão | WordPress | Next.js |
|----------|-----------|---------|
| Tempo de carregamento (LCP típico) | 2.5 – 5s | 0.6 – 1.5s |
| Lighthouse score (médio, mobile) | 35-70 | 90-100 |
| Custo de infra | €5-30/mês (shared) ou €50+ (VPS) | €0-20/mês (Vercel free tier cobre muito) |
| Atualização de segurança | Manual ou plugin | Build incremental da framework |
| Tempo para criar nova página | 5 min (CMS) | 30 min (código) ou 5 min (CMS headless) |
| Curva de aprendizagem para editores | Baixa | Depende do setup |
| Vulnerabilidades de plugin | Vetor #1 de hack | Quase inexistente |

## Quando Next.js vence

Migre para Next.js quando:

- **Performance importa para o negócio.** Se vende online ou compete por SEO, cada 100ms de LCP = 1-2% de conversão. WordPress raramente entrega menos de 2s sem investimento pesado em otimização.
- **Precisa de funcionalidade dinâmica.** Calculadoras, formulários multi-step, integrações com APIs, dashboard com login — WordPress torna-se uma improvisação. Next.js é nativo nisto.
- **A sua equipa tem (ou consegue contratar) developer.** Mercado de developer React/Next.js é enorme. Mercado de bom developer WordPress encolheu.
- **Quer Core Web Vitals impecáveis.** O Google penaliza sites lentos desde 2021. Next.js + Vercel entrega 95-100 no Lighthouse sem esforço.
- **Segurança é crítica.** Site institucional de empresa B2B, governo, financeiro. Plugins WordPress são vetor recorrente de invasão.

## Quando WordPress ainda é a escolha certa

Sou suspeito (construo em [Next.js](/pt-PT)), mas WordPress ainda é certo quando:

- **Conteúdo muda diariamente e editores não-técnicos publicam.** Blog de notícias, revista. WordPress nasceu para isto e é imbatível.
- **Orçamento é €1-3k total.** WordPress + tema bom + dev freelancer entrega site institucional decente. Next.js vai custar 3-5x mais nessa faixa.
- **Precisa de loja online barata e simples.** WooCommerce + tema sai mais barato no início do que Next.js + Stripe + tudo personalizado.
- **Quer parar de pagar developer após o lançamento.** WordPress + cliente a editar diretamente = manutenção quase zero. Next.js precisa de developer para mudanças estruturais.

## O custo real da migração

Não é só o preço da nova build. Some:

- **Migração de conteúdo.** WordPress → Next.js precisa de export, parse, reformat. Para 200 páginas: 20-40 horas.
- **301 redirects.** Cada URL antigo precisa apontar para o novo. Esquecer isto = perder 30-60% de tráfego orgânico nos primeiros 90 dias.
- **Headless CMS (se os editores precisarem).** Sanity, Contentful, Payload — €0-200/mês.
- **Formação da equipa.** 2-4 horas para editores aprenderem o novo fluxo.

Soma realista para um site institucional de 50 páginas: **€5-12k de build + 1-3 semanas de migração**.

## SEO depois da migração

Este é o medo número um. A verdade:

- **Curto prazo (1-3 meses):** queda de 10-30% no tráfego orgânico se fizer redirects bem feitos. Se esquecer redirects: queda de 50-80%.
- **Médio prazo (3-6 meses):** recuperação total + ganho de 10-40% pelos Core Web Vitals melhores.
- **Longo prazo (6+ meses):** ganho consistente se mantiver bom conteúdo.

Truque para reduzir risco: faça a migração técnica e mantenha URLs idênticos por 60 dias antes de qualquer rebranding ou alteração de conteúdo.

## A decisão de stack para cada caso

**Site institucional + landing pages:** Next.js + Sanity ou Payload. Sem dúvida.

**Blog/revista de notícias:** WordPress, a não ser que tenha equipa de developers dedicada.

**E-commerce até €200k ARR:** Shopify ou WooCommerce. Acima disso, vale Next.js + Shopify Hydrogen ou Medusa.

**App com login e dashboard:** Next.js. WordPress nunca foi feito para isto.

**Portal governamental / autarquia:** Next.js + headless CMS. Mais auditável, mais seguro, melhor performance.

## Checklist de quando vale o investimento

Marque mentalmente:

- [ ] Site atual tem Lighthouse < 70 no mobile
- [ ] Tráfego mensal > 10k visitas (cada % de melhoria conta)
- [ ] Já fui pirateado ou vivi com receio disso
- [ ] Plugins partem quando atualizo
- [ ] Quero adicionar funcionalidade custom e cada plugin é um pesadelo
- [ ] Custo de manutenção mensal passa de €200

3 ou mais? Vale conversar sobre migração. Menos do que isso? Mantenha o que tem e invista o dinheiro noutro lado.
